## Projects

- **[ProjectNotes](https://github.com/kestermckinney/ProjectNotes)** — a workspace for meeting notes, action items, project metrics, reporting, and workflow automation.
- **[SqliteSyncPro](https://github.com/kestermckinney/SqliteSyncPro)** — a Qt and C++ library for synchronizing local SQLite data with a shared PostgreSQL store.
- **[ScheduleIO](https://github.com/kestermckinney/ScheduleIO)** — a Qt and C++ library for working with Microsoft Project schedule files and scheduling data.
- **[SeeMyMac](https://github.com/kestermckinney/SeeMyMac)** — a Rust and GPUI screen-sharing client for connecting to a Mac from Windows and Linux, using Apple's High Performance Screen Sharing video alongside standard VNC. Read more on the [project page](https://kestermckinney.github.io/projects/seemymac.html).
- **[Legion Light](https://github.com/kestermckinney/legionlight)** — a Rust application for controlling the keyboard backlight on a supported Lenovo Legion laptop. There's also a separate [GNOME Shell extension](https://github.com/kestermckinney/GnomeLegionLight).

I work across project leadership, manufacturing systems, and software development. Lately, I've been building with Qt, C++, Rust, and GPUI, with a particular interest in desktop tools and offline-first workflows.
